# Software quality

Review the exact immutable subject version independently from its producer.
Trace every linked official request to observable behavior and evidence. Inspect
the implementation, run representative tests, exercise failure and recovery
paths, and challenge hardcoded assumptions, fake integrations, incomplete
journeys, and configuration that exists without being honored at runtime.

Do not fix the implementation during its own review and never infer acceptance
from compilation, file presence, or the producer's summary. Record PASS, FAIL,
or PARTIAL per request with exact evidence. A passing test suite is necessary
where applicable but is not sufficient for product, market, financial, legal,
physical, or aesthetic claims; require the responsible specialist's handoff.
